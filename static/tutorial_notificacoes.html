1

Entendendo a URL do WebSocket

Enquanto requisições tradicionais utilizam http:// e https://, os WebSockets utilizam ws:// e wss:// (com criptografia SSL).

☁️
Servidor na Nuvem (Render)
wss://api-produtos-mobile.onrender.com/ws/notificacoes
🤖
Emulador Android (Local)
ws://10.0.2.2:8000/ws/notificacoes
🍎
Simulador iOS / Web (Local)
ws://localhost:8000/ws/notificacoes
ℹ️ Por que 'wss://' no Render?

O Render opera sob HTTPS seguro. Se você tentar conectar usando ws:// (sem o s) na URL do Render, a conexão será recusada pelo navegador ou pelo sistema operacional do celular.

2

Conectando no Flutter com dart:io Nativo

Você não precisa alterar seu pubspec.yaml. O pacote dart:io já oferece suporte integrado a WebSockets!

No arquivo onde sua tela está declarada (ex.: lib/main.dart), declare a variável do WebSocket e a função de conexão:

lib/main.dart (Função de Conexão) 
import 'dart:io';   // Contém a classe WebSocket
import 'dart:convert'; // Para fazer o jsonDecode

class _TelaListaProdutosState extends State<TelaListaProdutos> {
  // Variável para armazenar a conexão ativa
  WebSocket? _canalWebSocket;

  void _conectarNotificacoes() async {
    try {
      // URL do WebSocket no Render
      final wsUrl = 'wss://api-produtos-mobile.onrender.com/ws/notificacoes';
      
      _canalWebSocket = await WebSocket.connect(wsUrl);
      print('✅ Conectado com sucesso ao canal de notificações!');

      // Fica ouvindo os disparos enviados pelo servidor
      _canalWebSocket!.listen(
        (dadoRecebido) {
          // O dado chega em formato String JSON: {"titulo": "...", "mensagem": "..."}
          final Map<String, dynamic> notificacao = jsonDecode(dadoRecebido);

          final String titulo = notificacao['titulo'] ?? 'Aviso';
          final String mensagem = notificacao['mensagem'] ?? '';

          // Exibe na interface do usuário
          _exibirAlertaPush(titulo, mensagem);
        },
        onError: (erro) {
          print('❌ Erro no canal WebSocket: $erro');
        },
        onDone: () {
          print('⚠️ Conexão WebSocket encerrada pelo servidor.');
        },
      );
    } catch (e) {
      print('Falha ao iniciar WebSocket: $e');
    }
  }
  ...
}
3

Criando o Banner Visual de Notificação (In-App Push)

Quando a notificação chega, usamos um SnackBar flutuante personalizado com ícone de sino e animação, simulando perfeitamente um push de sistema:

lib/main.dart (_exibirAlertaPush) 
void _exibirAlertaPush(String titulo, String mensagem) {
  // Verifica se a tela ainda está montada antes de desenhar na UI
  if (!mounted) return;

  ScaffoldMessenger.of(context).showSnackBar(
    SnackBar(
      backgroundColor: Colors.indigo.shade900,
      behavior: SnackBarBehavior.floating,
      shape: RoundedRectangleBorder(
        borderRadius: BorderRadius.circular(12),
      ),
      margin: const EdgeInsets.all(16),
      duration: const Duration(seconds: 5),
      content: Row(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          const Icon(
            Icons.notifications_active, 
            color: Colors.amber, 
            size: 28
          ),
          const SizedBox(width: 12),
          Expanded(
            child: Column(
              mainAxisSize: MainAxisSize.min,
              crossAxisAlignment: CrossAxisAlignment.start,
              children: [
                Text(
                  titulo,
                  style: const TextStyle(
                    fontWeight: FontWeight.bold,
                    fontSize: 14,
                    color: Colors.white,
                  ),
                ),
                const SizedBox(height: 2),
                Text(
                  mensagem,
                  style: const TextStyle(
                    fontSize: 13, 
                    color: Colors.white70
                  ),
                ),
              ],
            ),
          ),
        ],
      ),
    ),
  );
}
4

Gerenciando o Ciclo de Vida (initState e dispose)

Para que o canal abra assim que o app inicia e seja fechado de forma limpa quando o usuário sair da tela, utilize o initState e o dispose:

lib/main.dart (Ciclo de Vida) 
@override
void initState() {
  super.initState();
  _buscarProdutos();        // Busca os dados HTTP GET normais
  _conectarNotificacoes();  // Inicia a conexão WebSocket em segundo plano
}

@override
void dispose() {
  // Fecha a conexão WebSocket para não desperdiçar memória no aparelho
  _canalWebSocket?.close();
  super.dispose();
}

Como Testar em Tempo Real

Com o aplicativo rodando no seu dispositivo ou emulador:

  1. Abra o navegador no Swagger UI da API: /docs ↗
  2. Localize o endpoint POST /notificacoes/enviar e clique em Try it out.
  3. Preencha um título e uma mensagem de teste no corpo da requisição (JSON): 
    {
  "titulo": "🔥 Super Desconto",
  "mensagem": "Todos os produtos com frete grátis nos próximos 15 minutos!"
}
  4. Clique no botão azul Execute.
  5. Olhe para a tela do seu celular: a notificação surgirá instantaneamente!
