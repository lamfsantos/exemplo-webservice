💡 O que é o JWT (JSON Web Token)?

Pense no JWT como um crachá digital de acesso. Quando o usuário envia seu login e senha corretos para a API (POST /auth/login), o servidor emite esse crachá assinado digitalmente.

O app Flutter guarda esse crachá na memória do celular e, em todas as próximas requisições protegidas, apenas apresenta o crachá no cabeçalho Authorization: Bearer <token>. Assim, o servidor sabe quem é você sem precisar pedir sua senha a cada clique!

Fluxo de Vida da Sessão no App:
1 Usuário digita credenciais e clica em Entrar na LoginPage
2 App dispara POST /auth/login com o corpo JSON {"username": "...", "senha": "..."}
3 Servidor valida com BCrypt e responde 200 OK com o access_token JWT
4 App salva o token localmente com SharedPreferences e navega para a lista de produtos
5 Ao reabrir o aplicativo, o app lê o token salvo e entra direto, sem pedir login novamente!

Adicionando as Dependências no pubspec.yaml

Para fazer requisições HTTP e guardar o token com segurança no dispositivo, abra o arquivo pubspec.yaml do seu projeto Flutter e adicione o pacote shared_preferences logo abaixo de http:

pubspec.yaml 
dependencies:
  flutter:
    sdk: flutter
  http: ^1.2.0
  shared_preferences: ^2.2.2

Após salvar o arquivo, execute no terminal integrado do VS Code:

Terminal 
flutter pub get

Criando os Modelos de Dados (Models)

Vamos modelar as respostas da API para o token de acesso (retornado pelo login) e para os dados do usuário (retornado pelo cadastro e pelo perfil /auth/me).

lib/models/auth_models.dart 
// Resposta de sucesso do POST /auth/login
class LoginResponse {
  final String accessToken;
  final String tokenType;

  LoginResponse({
    required this.accessToken,
    required this.tokenType,
  });

  factory LoginResponse.fromJson(Map json) {
    return LoginResponse(
      accessToken: json['access_token'] ?? '',
      tokenType: json['token_type'] ?? 'bearer',
    );
  }
}

// Dados do Usuário (POST /auth/cadastrar e GET /auth/me)
class Usuario {
  final int id;
  final String username;
  final String nome;

  Usuario({
    required this.id,
    required this.username,
    required this.nome,
  });

  factory Usuario.fromJson(Map json) {
    return Usuario(
      id: json['id'] ?? 0,
      username: json['username'] ?? '',
      nome: json['nome'] ?? '',
    );
  }
}

Criando o Serviço de Autenticação (AuthService)

O AuthService é a classe responsável por fazer as chamadas de rede para a nossa API e salvar o token localmente no dispositivo.

⚠️ Atenção à URL Base no Flutter
  • Emulador Android (Android Studio): use http://10.0.2.2:8000 (pois localhost aponta para o próprio celular).
  • Simulador iOS ou Navegador Web: use http://localhost:8000.
  • Aparelho físico conectado via Wi-Fi: use o IP local do seu computador (ex: http://192.168.1.15:8000).
lib/services/auth_service.dart 
import 'dart:convert';
import 'package:http/http.dart' as http;
import 'package:shared_preferences/shared_preferences.dart';
import '../models/auth_models.dart';

class AuthService {
  // Altere para seu IP se estiver testando em aparelho físico
  static const String baseUrl = 'http://10.0.2.2:8000';
  static const String tokenKey = 'jwt_token';

  // 1. FAZER LOGIN (POST /auth/login)
  Future login(String username, String senha) async {
    final url = Uri.parse('$baseUrl/auth/login');

    final response = await http.post(
      url,
      headers: {'Content-Type': 'application/json'},
      body: jsonEncode({
        'username': username.trim(),
        'senha': senha,
      }),
    );

    if (response.statusCode == 200) {
      final dados = jsonDecode(response.body);
      final loginResp = LoginResponse.fromJson(dados);

      // Salva o token no aparelho
      await salvarToken(loginResp.accessToken);
      return loginResp.accessToken;
    } else if (response.statusCode == 401) {
      final erro = jsonDecode(response.body);
      throw Exception(erro['detail'] ?? 'Usuário ou senha inválidos.');
    } else {
      throw Exception('Erro ao conectar ao servidor (${response.statusCode})');
    }
  }

  // 2. CADASTRAR NOVO USUÁRIO (POST /auth/cadastrar)
  Future cadastrar({
    required String username,
    required String senha,
    required String nome,
  }) async {
    final url = Uri.parse('$baseUrl/auth/cadastrar');

    final response = await http.post(
      url,
      headers: {'Content-Type': 'application/json'},
      body: jsonEncode({
        'username': username.trim(),
        'senha': senha,
        'nome': nome.trim(),
      }),
    );

    if (response.statusCode == 201) {
      final dados = jsonDecode(utf8.decode(response.bodyBytes));
      return Usuario.fromJson(dados);
    } else if (response.statusCode == 400) {
      final erro = jsonDecode(utf8.decode(response.bodyBytes));
      throw Exception(erro['detail'] ?? 'Nome de usuário indisponível.');
    } else {
      throw Exception('Erro no cadastro (${response.statusCode})');
    }
  }

  // 3. CONSULTAR PERFIL LOGADO (GET /auth/me com Bearer Token)
  Future obterPerfil() async {
    final token = await obterToken();
    if (token == null) return null;

    final url = Uri.parse('$baseUrl/auth/me');
    final response = await http.get(
      url,
      headers: {
        'Content-Type': 'application/json',
        'Authorization': 'Bearer $token',
      },
    );

    if (response.statusCode == 200) {
      final dados = jsonDecode(utf8.decode(response.bodyBytes));
      return Usuario.fromJson(dados);
    }
    return null;
  }

  // MÉTODOS DE SESSÃO LOCAL COM SHAREDPREFERENCES
  Future salvarToken(String token) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString(tokenKey, token);
  }

  Future obterToken() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getString(tokenKey);
  }

  Future logout() async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.remove(tokenKey);
  }
}

Construindo a Tela de Login (LoginPage)

A tela de login deve fornecer campos intuitivos para usuário e senha, exibir um indicador de carregamento durante a requisição e mostrar um alerta amigável (via SnackBar) se as credenciais estiverem incorretas.

lib/pages/login_page.dart 
import 'package:flutter/material.dart';
import '../services/auth_service.dart';
import 'cadastro_page.dart';
import 'produtos_page.dart';

class LoginPage extends StatefulWidget {
  const LoginPage({super.key});

  @override
  State createState() => _LoginPageState();
}

class _LoginPageState extends State {
  final _formKey = GlobalKey();
  final _usuarioCtrl = TextEditingController(text: 'aluno');
  final _senhaCtrl = TextEditingController(text: '123456');
  final _authService = AuthService();

  bool _carregando = false;
  bool _ocultarSenha = true;

  Future _fazerLogin() async {
    if (!_formKey.currentState!.validate()) return;

    setState(() => _carregando = true);

    try {
      await _authService.login(_usuarioCtrl.text, _senhaCtrl.text);

      if (!mounted) return;
      // Login com sucesso: vai para a tela de produtos
      Navigator.pushReplacement(
        context,
        MaterialPageRoute(builder: (context) => const ProdutosPage()),
      );
    } catch (e) {
      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: Text(e.toString().replaceAll('Exception: ', '')),
          backgroundColor: Colors.redAccent,
          behavior: SnackBarBehavior.floating,
        ),
      );
    } finally {
      if (mounted) setState(() => _carregando = false);
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: const Color(0xFF0F172A),
      body: Center(
        child: SingleChildScrollView(
          padding: const EdgeInsets.all(24.0),
          child: ConstrainedBox(
            constraints: const BoxConstraints(maxWidth: 400),
            child: Form(
              key: _formKey,
              child: Column(
                mainAxisAlignment: MainAxisAlignment.center,
                children: [
                  // Ícone de Segurança
                  Container(
                    width: 72,
                    height: 72,
                    decoration: BoxDecoration(
                      color: const Color(0xFF6366F1),
                      borderRadius: BorderRadius.circular(20),
                      boxShadow: [
                        BoxShadow(
                          color: const Color(0xFF6366F1).withOpacity(0.4),
                          blurRadius: 20,
                          offset: const Offset(0, 8),
                        ),
                      ],
                    ),
                    child: const Icon(Icons.lock_outline, size: 36, color: Colors.white),
                  ),
                  const SizedBox(height: 24),
                  const Text(
                    'Acessar Catálogo',
                    style: TextStyle(fontSize: 26, fontWeight: FontWeight.bold, color: Colors.white),
                  ),
                  const SizedBox(height: 8),
                  const Text(
                    'Informe suas credenciais para continuar',
                    style: TextStyle(color: Color(0xFF94A3B8)),
                  ),
                  const SizedBox(height: 32),

                  // Campo Usuário
                  TextFormField(
                    controller: _usuarioCtrl,
                    style: const TextStyle(color: Colors.white),
                    decoration: InputDecoration(
                      labelText: 'Nome de Usuário',
                      labelStyle: const TextStyle(color: Color(0xFF94A3B8)),
                      prefixIcon: const Icon(Icons.person_outline, color: Color(0xFF818CF8)),
                      filled: true,
                      fillColor: const Color(0xFF1E293B),
                      border: OutlineInputBorder(borderRadius: BorderRadius.circular(12), borderSide: BorderSide.none),
                    ),
                    validator: (v) => (v == null || v.isEmpty) ? 'Informe seu usuário' : null,
                  ),
                  const SizedBox(height: 16),

                  // Campo Senha
                  TextFormField(
                    controller: _senhaCtrl,
                    obscureText: _ocultarSenha,
                    style: const TextStyle(color: Colors.white),
                    decoration: InputDecoration(
                      labelText: 'Senha',
                      labelStyle: const TextStyle(color: Color(0xFF94A3B8)),
                      prefixIcon: const Icon(Icons.key_outlined, color: Color(0xFF818CF8)),
                      suffixIcon: IconButton(
                        icon: Icon(_ocultarSenha ? Icons.visibility_off : Icons.visibility, color: const Color(0xFF94A3B8)),
                        onPressed: () => setState(() => _ocultarSenha = !_ocultarSenha),
                      ),
                      filled: true,
                      fillColor: const Color(0xFF1E293B),
                      border: OutlineInputBorder(borderRadius: BorderRadius.circular(12), borderSide: BorderSide.none),

                    validator: (v) => (v == null || v.length < 4) ? 'Mínimo de 4 caracteres' : null,

                  // Link para Cadastro

                    onPressed: () {
                      Navigator.push(
                        context,

Conectando a Sessão, Perfil e Botão de Logout

Agora integramos a autenticação com a tela de catálogo de produtos que os alunos já construíram na Atividade 1:

  1. Verificação Automática no Início (Splash/AuthCheck): Se já existir um token salvo no dispositivo, o app abre direto nos produtos. Caso contrário, abre o Login.
  2. Exibir Perfil do Usuário: Usando o endpoint protegido GET /auth/me com o cabeçalho Authorization: Bearer <token>, exibimos uma saudação com o nome do aluno.
  3. Botão de Logout: Na AppBar da lista de produtos, adicionamos um botão para limpar a chave do token e voltar à tela de login.
💡 Como o Logout funciona com JWT?

Como os tokens JWT são stateless (não guardam estado no servidor), o logout no cliente é extremamente simples e eficiente: basta remover o token do SharedPreferences e redirecionar para a LoginPage!

class CadastroPage extends StatefulWidget {
  const CadastroPage({super.key});

  @override
  State createState() => _CadastroPageState();
}

class _CadastroPageState extends State {
  final _formKey = GlobalKey();
  final _nomeCtrl = TextEditingController();
  final _usuarioCtrl = TextEditingController();
  final _senhaCtrl = TextEditingController();
  bool _carregando = false;

  Future _fazerCadastro() async {
    if (!_formKey.currentState!.validate()) return;
    setState(() => _carregando = true);

    try {
      final response = await http.post(
        Uri.parse('$apiBaseUrl/auth/cadastrar'),
        headers: {'Content-Type': 'application/json'},
        body: jsonEncode({
          'nome': _nomeCtrl.text.trim(),
          'username': _usuarioCtrl.text.trim(),
          'senha': _senhaCtrl.text,
        }),
      );

      if (response.statusCode == 201) {
        if (!mounted) return;
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(
            content: Text('Usuário cadastrado com sucesso! Faça login.'),
            backgroundColor: Colors.green,
          ),
        );
        Navigator.pop(context);
      } else {
        final erro = jsonDecode(utf8.decode(response.bodyBytes));
        throw Exception(erro['detail'] ?? 'Erro no cadastro.');
      }
    } catch (e) {
      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: Text(e.toString().replaceAll('Exception: ', '')),
          backgroundColor: Colors.redAccent,
        ),
      );
    } finally {
      if (mounted) setState(() => _carregando = false);
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Cadastrar Conta'), backgroundColor: Colors.transparent, elevation: 0),
      body: Center(
        child: SingleChildScrollView(

                      filled: true,
                      fillColor: const Color(0xFF1E293B),
                      border: OutlineInputBorder(borderRadius: BorderRadius.circular(12), borderSide: BorderSide.none),
                    ),
                    validator: (v) => (v == null || v.isEmpty) ? 'Informe seu nome' : null,
                  ),
                  const SizedBox(height: 14),

                  TextFormField(
                    controller: _usuarioCtrl,
                    style: const TextStyle(color: Colors.white),
                    decoration: InputDecoration(

class ProdutosPage extends StatefulWidget {
  const ProdutosPage({super.key});

  @override
  State createState() => _ProdutosPageState();
}

class _ProdutosPageState extends State {
  String _nomeUsuario = 'Carregando...';
  List _produtos = [];
  bool _carregando = true;

  @override
  void initState() {
    super.initState();
    _carregarDados();
  }

  Future _carregarDados() async {
    setState(() => _carregando = true);
    final prefs = await SharedPreferences.getInstance();
    final token = prefs.getString(tokenKey) ?? '';

    try {
      // 1. Busca perfil do usuário autenticado no /auth/me
      final respUser = await http.get(
        Uri.parse('$apiBaseUrl/auth/me'),
        headers: {'Authorization': 'Bearer $token'},
      );
      if (respUser.statusCode == 200) {
        final dadosUser = jsonDecode(utf8.decode(respUser.bodyBytes));
        setState(() => _nomeUsuario = dadosUser['nome'] ?? dadosUser['username']);
      }

      // 2. Busca lista de produtos
      final respProd = await http.get(Uri.parse('$apiBaseUrl/produtos'));
      if (respProd.statusCode == 200) {
        setState(() => _produtos = jsonDecode(utf8.decode(respProd.bodyBytes)));
      }
    } catch (_) {
      // Trata erros de rede se necessário
    } finally {
      if (mounted) setState(() => _carregando = false);
    }
  }

  Future _fazerLogout() async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.remove(tokenKey); // Remove o token local

    if (!mounted) return;
    Navigator.pushReplacement(
      context,
      MaterialPageRoute(builder: (context) => const LoginPage()),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            const Text('Catálogo de Produtos', style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold)),
            Text('Olá, $_nomeUsuario 👋', style: const TextStyle(fontSize: 12, color: Color(0xFF818CF8))),
          ],
        ),
        actions: [
          IconButton(
            icon: const Icon(Icons.logout, color: Colors.redAccent),
            tooltip: 'Sair da Conta',
            onPressed: _fazerLogout,
          ),
        ],
      ),
      body: _carregando
          ? const Center(child: CircularProgressIndicator(color: Color(0xFF6366F1)))
          : ListView.builder(
              padding: const EdgeInsets.all(12),
              itemCount: _produtos.length,
              itemBuilder: (context, index) {
                final prod = _produtos[index];
                return Card(
                  color: const Color(0xFF1E293B),
                  margin: const EdgeInsets.symmetric(vertical: 6),
                  shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(12)),
                  child: ListTile(
                    leading: CircleAvatar(
                      backgroundColor: const Color(0xFF6366F1).withOpacity(0.2),
                      child: const Icon(Icons.shopping_bag_outlined, color: Color(0xFF818CF8)),
                    ),
                    title: Text(prod['nome'], style: const TextStyle(fontWeight: FontWeight.bold, color: Colors.white)),
                    subtitle: Text(
                      prod['descricao'] ?? '',
                      maxLines: 1,
                      overflow: TextOverflow.ellipsis,
                      style: const TextStyle(color: Color(0xFF94A3B8)),
                    ),
                    trailing: Text(
                      'R\$ ${(prod['preco'] as num).toStringAsFixed(2)}',
                      style: const TextStyle(fontWeight: FontWeight.bold, color: Color(0xFF34D399), fontSize: 14),
                    ),
                  ),
                );
              },
            ),
    );
  }
}
