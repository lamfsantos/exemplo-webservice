Criando o Novo Projeto no VS Code

O Visual Studio Code oferece comandos integrados que geram toda a estrutura inicial do aplicativo Flutter sem precisar abrir o terminal manualmente.

⌨️
1. Abra a Paleta de Comandos
Pressione Ctrl + Shift + P (no Windows/Linux) ou Cmd + Shift + P (no macOS).
🚀
2. Comando Novo Projeto
Digite Flutter: New Project (ou Create New Project) e tecle Enter.
📱
3. Selecione Application
Escolha o modelo Application para criar um aplicativo padrão.
📁
4. Escolha a Pasta e Nome
Indique a pasta de destino e digite o nome do projeto (ex.: client). Pressione Enter.
ℹ️ Estrutura Gerada

Após alguns segundos, o VS Code abrirá a pasta com arquivos como pubspec.yaml (gerenciador de dependências) e a pasta lib/ com o arquivo principal main.dart.

2

Adicionando o Pacote HTTP

O Flutter/Dart por padrão não inclui um cliente HTTP com alto nível de abstração. Para fazer requisições GET, POST, etc., usamos o pacote oficial http da comunidade Dart.

Opção A: Pelo Terminal Integrado (Mais Rápido)

No VS Code, abra o terminal integrado (Ctrl + ` ou menu Terminal > New Terminal) e execute:

Terminal 
flutter pub add http

Opção B: Manualmente no pubspec.yaml

Abra o arquivo pubspec.yaml na raiz do projeto e declare o pacote sob a chave dependencies::

pubspec.yaml 
dependencies:
  flutter:
    sdk: flutter

  # Pacote oficial para requisições HTTP (GET, POST, etc.)
  http: ^1.2.0

  cupertino_icons: ^1.0.8

Ao salvar o arquivo, o VS Code executará automaticamente o comando flutter pub get para baixar a biblioteca.

3

Permissão de Acesso à Internet no Android

Para que o aplicativo possa se conectar a servidores externos quando compilado para Android, é uma boa prática garantir a permissão de INTERNET no arquivo de manifesto.

Abra o arquivo android/app/src/main/AndroidManifest.xml e adicione a seguinte linha antes da tag <application>:

android/app/src/main/AndroidManifest.xml 
<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    <!-- Permissão necessária para fazer chamadas HTTP na rede -->
    <uses-permission android:name="android.permission.INTERNET"/>

    <application
        android:label="client"
        ...>
        ...
    </application>
</manifest>
💡 Dica sobre modo Debug

No modo Debug, o Flutter habilita a permissão temporária automaticamente para fins de desenvolvimento, mas para compilar APK ou evitar falhas de rede em emuladores, declarar a permissão no manifesto é fundamental.

Criando o Modelo de Dados (Model / DTO)

A API em https://api-produtos-mobile.onrender.com/produtos devolve uma lista de objetos JSON com esta estrutura:

Exemplo de JSON da API 
[
  {
    "id": 1,
    "nome": "Smartphone Galaxy A15",
    "preco": 1199.0,
    "descricao": "Tela 6.5 Super AMOLED, 128GB, 4GB RAM, Bateria 5000mAh",
    "disponivel": true
  }
]

Para trabalhar de forma segura (Type Safety) e com autocompletar, criamos a classe Produto com um Factory Constructor Produto.fromJson:

lib/main.dart (Seção do Model) 
class Produto {
  final int id;
  final String nome;
  final double preco;
  final String? descricao; // Opcional (pode ser nulo)
  final bool disponivel;

  Produto({
    required this.id,
    required this.nome,
    required this.preco,
    this.descricao,
    required this.disponivel,
  });

  /// Construtor de fábrica para transformar o Map do JSON em Objeto Dart
  factory Produto.fromJson(Map<String, dynamic> json) {
    return Produto(
      id: json['id'] as int,
      nome: json['nome'] as String,
      // Usamos toDouble() porque o número no JSON pode vir como int (ex: 1200) ou double (1199.90)
      preco: (json['preco'] as num).toDouble(),
      descricao: json['descricao'] as String?,
      disponivel: json['disponivel'] as bool? ?? false,
    );
  }
}

Gerenciamento de Estado com StatefulWidget

A tela precisa reagir e redesenhar conforme a requisição acontece. Usamos um StatefulWidget com três variáveis de controle:

  • List<Produto> _produtos = []; — Armazena os itens recebidos com sucesso.
  • bool _carregando = true; — Indica se a requisição está em andamento para exibir o spinner.
  • String? _mensagemErro; — Se houver falha de rede ou timeout, armazena a mensagem para alertar o usuário.
lib/main.dart (Ciclo de Vida) 
class TelaListaProdutos extends StatefulWidget {
  const TelaListaProdutos({super.key});

  @override
  State<TelaListaProdutos> createState() => _TelaListaProdutosState();
}

class _TelaListaProdutosState extends State<TelaListaProdutos> {
  final String _apiUrl = 'https://api-produtos-mobile.onrender.com/produtos';

  List<Produto> _produtos = [];
  bool _carregando = true;
  String? _mensagemErro;

  // initState roda uma única vez quando a tela é carregada pela primeira vez
  @override
  void initState() {
    super.initState();
    _buscarProdutos(); // Dispara a busca inicial na API
  }
  ...
}

Consumindo a API (Método GET e Tratamento de Erros)

Aqui implementamos o método assíncrono _buscarProdutos(). Ele faz a chamada HTTP, aguarda a resposta (await), trata acentuação UTF-8 e converte os dados.

⚠️ Atenção: Servidor no Render (Cold Start)

Como o backend gratuito no Render entra em modo "hibernação" quando fica ocioso, a primeira requisição pode levar cerca de 30 a 50 segundos para "acordar". Por isso, definimos um .timeout(const Duration(seconds: 45)) para não abortar antes da hora.

lib/main.dart (_buscarProdutos) 
Future<void> _buscarProdutos() async {
  setState(() {
    _carregando = true;
    _mensagemErro = null;
  });

  try {
    final uri = Uri.parse(_apiUrl);
    
    // Faz a requisição HTTP GET com timeout de 45 segundos
    final resposta = await http.get(uri).timeout(
      const Duration(seconds: 45),
    );

    if (resposta.statusCode == 200) {
      // Usamos utf8.decode para garantir que caracteres especiais (ã, é, ç) não fiquem corrompidos
      final List<dynamic> dadosJson = jsonDecode(utf8.decode(resposta.bodyBytes));

      // Transforma a lista de maps em lista de objetos Produto
      final List<Produto> listaCarregada = dadosJson
          .map((item) => Produto.fromJson(item as Map<String, dynamic>))
          .toList();

      setState(() {
        _produtos = listaCarregada;
        _carregando = false;
      });
    } else {
      setState(() {
        _mensagemErro = 'Erro no servidor: Código HTTP ${resposta.statusCode}';
        _carregando = false;
      });
    }
  } on SocketException {
    setState(() {
      _mensagemErro = 'Falha de conexão. Verifique sua internet ou a URL da API.';
      _carregando = false;
    });
  } on http.ClientException {
    setState(() {
      _mensagemErro = 'Não foi possível conectar ao servidor da API.';
      _carregando = false;
    });
  } catch (e) {
    setState(() {
      _mensagemErro = 'Ocorreu um erro inesperado: $e';
      _carregando = false;
    });
  }
}

Construindo a Interface (UI) Moderna

O método _construirCorpo() divide a tela em 4 estados possíveis, garantindo que o usuário nunca veja uma tela em branco ou confusa:

⏳
1. Estado Carregando
Exibe CircularProgressIndicator e mensagem avisando que a API pode demorar a acordar.
❌
2. Estado de Erro
Mostra o ícone de alerta, a mensagem exata do erro e um botão Tentar Novamente.
📭
3. Estado Vazio
Se a lista retornar 0 itens, exibe uma mensagem amigável de catálogo vazio.
✨
4. Estado Sucesso
Exibe a lista com RefreshIndicator (puxar para baixo para atualizar) e ListView.builder com Cards.
lib/main.dart (ListView.builder com Cards) 
RefreshIndicator(
  onRefresh: _buscarProdutos,
  child: ListView.builder(
    padding: const EdgeInsets.symmetric(horizontal: 12, vertical: 8),
    itemCount: _produtos.length,
    itemBuilder: (context, index) {
      final produto = _produtos[index];

      return Card(
        elevation: 2,
        margin: const EdgeInsets.symmetric(vertical: 6),
        shape: RoundedRectangleBorder(
          borderRadius: BorderRadius.circular(12),
        ),
        child: Padding(
          padding: const EdgeInsets.all(12.0),
          child: Row(
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              // Círculo com o ID
              CircleAvatar(
                backgroundColor: produto.disponivel
                    ? Colors.teal.shade50
                    : Colors.grey.shade200,
                foregroundColor: produto.disponivel
                    ? Colors.teal
                    : Colors.grey.shade600,
                child: Text('#${produto.id}'),
              ),
              const SizedBox(width: 14),

              // Nome, Descrição e Preço
              Expanded(
                child: Column(
                  crossAxisAlignment: CrossAxisAlignment.start,
                  children: [
                    Text(
                      produto.nome,
                      style: const TextStyle(
                        fontSize: 16,
                        fontWeight: FontWeight.bold,
                      ),
                    ),
                    if (produto.descricao != null && produto.descricao!.isNotEmpty) ...[
                      const SizedBox(height: 4),
                      Text(
                        produto.descricao!,
                        style: TextStyle(fontSize: 13, color: Colors.grey.shade700),
                      ),
                    ],
                    const SizedBox(height: 8),
                    Text(
                      'R\$ ${produto.preco.toStringAsFixed(2)}',
                      style: const TextStyle(
                        fontSize: 15,
                        fontWeight: FontWeight.w600,
                        color: Colors.teal,
                      ),
                    ),
                  ],
                ),
              ),

              // Chip de Disponibilidade
              Chip(
                label: Text(
                  produto.disponivel ? 'Disponível' : 'Esgotado',
                  style: TextStyle(
                    fontSize: 11,
                    color: produto.disponivel ? Colors.green.shade800 : Colors.red.shade800,
                    fontWeight: FontWeight.w600,
                  ),
                ),
                backgroundColor: produto.disponivel ? Colors.green.shade50 : Colors.red.shade50,
                side: BorderSide.none,
                padding: EdgeInsets.zero,
              ),
            ],
          ),
        ),
      );
    },
  ),
);

Código Completo do main.dart

Substitua todo o conteúdo existente no arquivo lib/main.dart pelo código pronto abaixo. Ele já contém todos os imports, a classe Produto, as chamadas com timeout, a decodificação UTF-8 e a interface responsiva.

lib/main.dart 
import 'dart:convert'; // Necessário para converter JSON em estruturas do Dart (Map e List)

import 'package:flutter/material.dart';
import 'package:http/http.dart' as http; // Pacote responsável por fazer requisições HTTP (GET, POST, etc.)

void main() {

}

/// Widget raiz da aplicação
class MyApp extends StatelessWidget {
  const MyApp({super.key});

  Widget build(BuildContext context) {

// 2. TELA PRINCIPAL (STATEFUL WIDGET)
// ==============================================================================
class TelaListaProdutos extends StatefulWidget {
  const TelaListaProdutos({super.key});

  @override
  State<TelaListaProdutos> createState() => _TelaListaProdutosState();
}

class _TelaListaProdutosState extends State<TelaListaProdutos> {
  // URL da API externa no Render
  final String _apiUrl = 'https://api-produtos-mobile.onrender.com/produtos';

  // Estados da tela
  List<Produto> _produtos = [];
  bool _carregando = true;
  String? _mensagemErro;

  @override
  void initState() {
    super.initState();
    _buscarProdutos();
  }

  // ============================================================================
  // 3. FUNÇÃO ASSÍNCRONA PARA CONSUMIR O MÉTODO GET
  // ============================================================================
  Future<void> _buscarProdutos() async {
    setState(() {
      _carregando = true;
      _mensagemErro = null;
    });

    try {
      final uri = Uri.parse(_apiUrl);
      final resposta = await http.get(uri).timeout(
        const Duration(seconds: 45), // Dá tempo para o Render "acordar" no primeiro acesso
      );

      if (resposta.statusCode == 200) {
        // utf8.decode garante acentuação correta
        final List<dynamic> dadosJson = jsonDecode(utf8.decode(resposta.bodyBytes));

        final List<Produto> listaCarregada = dadosJson
            .map((item) => Produto.fromJson(item as Map<String, dynamic>))
            .toList();

        setState(() {
          _produtos = listaCarregada;
          _carregando = false;
        });
      } else {
        setState(() {
          _mensagemErro = 'Erro no servidor: Código HTTP ${resposta.statusCode}';
          _carregando = false;
        });
      }
    } on SocketException {
      setState(() {
        _mensagemErro = 'Falha de conexão. Verifique sua internet ou a URL da API.';
        _carregando = false;
      });
    } on http.ClientException {
      setState(() {
        _mensagemErro = 'Não foi possível conectar ao servidor da API.';
        _carregando = false;
      });
    } catch (e) {
      setState(() {
        _mensagemErro = 'Ocorreu um erro inesperado: $e';
        _carregando = false;
      });
    }
  }

  // ============================================================================
  // 4. CONSTRUÇÃO DA INTERFACE (UI)
  // ============================================================================
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Produtos (API Externa)'),
        centerTitle: true,
        actions: [
          IconButton(
            icon: const Icon(Icons.refresh),
            tooltip: 'Recarregar',
            onPressed: _carregando ? null : _buscarProdutos,
          ),
        ],
      ),
      body: _construirCorpo(),
    );
  }

  Widget _construirCorpo() {
    // ESTADO 1: Carregando
    if (_carregando) {
      return const Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            CircularProgressIndicator(),
            SizedBox(height: 16),
            Text(
              'Buscando produtos na API...\n(O servidor no Render pode levar ~40s para acordar)',
              textAlign: TextAlign.center,
              style: TextStyle(color: Colors.grey),
            ),
          ],
        ),
      );
    }

    // ESTADO 2: Erro
    if (_mensagemErro != null) {
      return Center(
        child: Padding(
          padding: const EdgeInsets.all(24.0),
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              const Icon(Icons.error_outline, size: 64, color: Colors.red),
              const SizedBox(height: 16),
              Text(
                _mensagemErro!,
                textAlign: TextAlign.center,
                style: const TextStyle(fontSize: 16),
              ),
              const SizedBox(height: 24),
              ElevatedButton.icon(
                onPressed: _buscarProdutos,
                icon: const Icon(Icons.refresh),
                label: const Text('Tentar Novamente'),
              ),
            ],
          ),
        ),
      );
    }

    // ESTADO 3: Lista Vazia
    if (_produtos.isEmpty) {
      return const Center(
        child: Text(
          'Nenhum produto cadastrado na API.',

    // ESTADO 4: Sucesso com RefreshIndicator
    return RefreshIndicator(
      onRefresh: _buscarProdutos,
      child: ListView.builder(
        padding: const EdgeInsets.symmetric(horizontal: 12, vertical: 8),
        itemCount: _produtos.length,
        itemBuilder: (context, index) {
          final produto = _produtos[index];

          return Card(
            elevation: 2,
            margin: const EdgeInsets.symmetric(vertical: 6),
            shape: RoundedRectangleBorder(
              borderRadius: BorderRadius.circular(12),
            ),
            child: Padding(
              padding: const EdgeInsets.all(12.0),
              child: Row(
                crossAxisAlignment: CrossAxisAlignment.start,
                children: [
                  CircleAvatar(
                    backgroundColor: produto.disponivel
                        ? Colors.teal.shade50
                        : Colors.grey.shade200,
                    foregroundColor: produto.disponivel
                        ? Colors.teal
                        : Colors.grey.shade600,
                    child: Text('#${produto.id}'),
                  ),
                  const SizedBox(width: 14),
                  Expanded(
                    child: Column(
                      crossAxisAlignment: CrossAxisAlignment.start,
